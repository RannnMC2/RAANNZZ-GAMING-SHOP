Frontend (Next.js) starter

Langkah menjalankan lokal:

1. Masuk ke folder frontend
   cd frontend
2. Install dependency
   npm install
3. Jalankan dev server
   npm run dev

Catatan: ini hanya starter minimal. Saya sarankan menambahkan Tailwind, ESLint, dan struktur komponen (pages, components, hooks, lib/api).
