# Backend starter (Express)

Langkah menjalankan lokal:

1. Salin environment example:
   cp .env.example .env
2. Install dependency:
   npm install
3. Jalankan server development:
   npm run dev

Endpoints contoh:
- GET /api/health
- GET /api/listings
- POST /api/listings

Catatan: ini hanya stub untuk memulai. Selanjutnya tambahkan database, autentikasi, validasi, dan migrasi.
